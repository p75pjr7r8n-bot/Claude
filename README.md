# Claude
## YouTube skills

Eleven YouTube skills from [jakeschincariol/youtube-agent-skill](https://github.com/jakeschincariol/youtube-agent-skill) (MIT) live in `.claude/skills/yt-*`. Claude Code picks them up automatically in this repo: `/yt-script`, `/yt-package`, `/yt-edit`, `/yt-comment`, `/yt-plan`, `/yt-viral`, `/yt-retention`, `/yt-shorts`, `/yt-seo`, `/yt-chapters`, `/yt-audit`.

Fill in `templates/voice.md` (or ask Claude to write it from three of your videos) and save it as `~/.claude/youtube/voice.md` — every skill reads it.
