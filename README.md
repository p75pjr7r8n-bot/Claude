# AI社員チーム

Claude Code で動く6人のAI社員です。

| 社員 | 頼めること |
|------|-----------|
| 秘書 | タスク整理、メール下書き、朝のブリーフ、議事録 |
| ライター | ブログ、プレスリリース、資料の文章 |
| リサーチャー | 市場調査、競合分析、出典付きレポート |
| エンジニア | 実装、レビュー、バグ修正、PR対応 |
| SNS担当 | 投稿案、投稿カレンダー、キャンペーン企画 |
| 企画担当 | 新商品・イベントの企画、企画書、実行計画 |

## 使い方

1. `CLAUDE.md` 末尾の「会社情報」を埋める。
2. このリポジトリで Claude Code を開き、普通に頼む。
   - 「来週の展示会の告知、ブログとXの投稿を作って」
   - 「秘書さん、今日のToDoを整理して」
   - 「researcher で競合3社の料金を比べて」
   - 「夏のキャンペーンを企画して」
3. Claude が内容に応じて担当の社員に振り分けます。社員を名指ししてもOKです。

## 構成

```
CLAUDE.md                 # チームのルールと振り分け
.claude/agents/           # 各AI社員の定義
.claude/skills/stop-slop/ # 文章からAIっぽさを除くスキル
output/                   # 成果物の保存先
```

## note の毎朝自動下書き

毎朝6時前に記事を1本作り、note の下書きに保存します。公開は自分で行います。

1. 体験メモを `note/inbox/` に入れる（書き方は `note/inbox/README.md`）
2. 朝の通知を見て、note の編集画面で確認・公開する
3. 曜日ごとの型やテーマは `note/settings.md` で変える

社員を増やすときは `.claude/agents/` に同じ形式の `.md` を追加し、`CLAUDE.md` のメンバー表に1行足します。
