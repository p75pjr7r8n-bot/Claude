# note 5アカウント運用

| フォルダ | ジャンル |
|----------|----------|
| `accounts/love` | 恋愛 |
| `accounts/beauty` | 美容 |
| `accounts/travel` | 旅行 |
| `accounts/worktips` | 仕事術 |
| `accounts/ai` | AI |

各アカウントのフォルダ：
- `settings.md`：テーマ、読者、曜日ごとの型、注意点
- `inbox/`：体験メモ置き場（1メモ1ファイル、`YYYY-MM-DD-なんでも.md`）。使ったメモは `inbox/used/` へ移る
- `drafts/`：作った記事
- `log.md`：下書きの記録

共通ルールは `common.md`、記事の型は `templates.md`。

## メモの書き方

箇条書きで十分です。「やったこと」「数字」「感じたこと・失敗」があると記事になります。スマホからは GitHub アプリでファイルを追加するか、Claude に「このメモを美容の inbox に入れて」と頼んでください。

```
- 夜のケアを化粧水と保湿クリームの2つだけにした
- 2週間続けた。朝のつっぱり感が減った
- 最初の3日は物足りなくて不安だった
```
