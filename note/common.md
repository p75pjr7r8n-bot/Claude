# 5アカウント共通のルール

毎朝の自動実行は、各アカウントの `settings.md` とこのファイルを読んで記事を作ります。

## アカウント一覧

| フォルダ | ジャンル | シークレット名 |
|----------|----------|----------------|
| `love` | 恋愛 | `NOTE_COOKIE_LOVE` |
| `beauty` | 美容 | `NOTE_COOKIE_BEAUTY` |
| `travel` | 旅行 | `NOTE_COOKIE_TRAVEL` |
| `worktips` | 仕事術 | `NOTE_COOKIE_WORKTIPS` |
| `ai` | AI | `NOTE_COOKIE_AI` |

シークレットが未登録のアカウントは、記事だけ作って note への保存を飛ばします。

## 守ること
- 体験談・数字は、そのアカウントの `inbox/` のメモにある事実だけを使う。メモにない体験や数字を作らない。
- メモがない日は、体験に頼らない記事（考え方、手順、ニュースの考察）にする。「私は〜した」と書かない。
- アカウント同士で、同じ人だと分かる書き方や相互の宣伝をしない。題材・言い回し・締め方もアカウント間で重ねない。
- 収入や効果の約束・断定をしない（「誰でも」「確実に」「必ず」）。
- 時事ネタは開いて確認したページだけを出典にし、記事末尾にURLを付ける。
- 文体：です・ます調。長さ：1,000〜2,000字（検証型は2,500字まで）。
