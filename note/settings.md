# note 自動下書きの設定

毎朝の自動実行はこのファイルを読んで記事を作ります。変えたいところはここを書き換えてください。

## 基本
- メインテーマ：AIで副業を回す実録（`output/planner/2026-10-26-note収益化企画.md`）
- 読者：副業を始めたいが時間がない30〜40代の会社員
- 一人称：私
- 文体：です・ます調。親しみやすく、煽らない
- 長さ：1,000〜2,000字（検証型は2,500字まで）

## 曜日ごとの型
型の中身は `note/templates.md`。元ネタは Docs「[note記事5本](https://claude.ai/artifact/4i8caqwRUop8crNoihDP5z)」です。

| 曜日 | 型 | 題材の例 |
|------|----|----------|
| 月 | 検証型 | 先週試したこと（AI社員、作業時間、収支）の記録 |
| 火 | エッセイ型 | AIを使って気づいたこと、失敗 |
| 水 | 時事考察型 | 副業・AI・働き方のニュースを自分の目線で考える |
| 木 | セールス型（煽りなし） | 有料記事・メンバーシップへの案内を兼ねたノウハウ |
| 金 | エッセイ型 | 副業と本業、時間の使い方 |
| 土 | 検証型 | ツールや方法を比べた結果 |
| 日 | 時事考察型 | 1週間のまとめと来週やること |

## 守ること
- 体験談・数字は `note/inbox/` のメモにある事実だけを使う。メモにない体験や数字を作らない。
- メモがない日は、体験に頼らない記事（考え方、手順、ニュースの考察）にする。「私は〜した」と書かない。
- 収入の約束・断定（「誰でも月◯万円」「確実に稼げる」）をしない。
- 投資の個別銘柄の売買をすすめない。
- 時事ネタは出典URLを記事末尾に付ける。確認できない話題は使わない。
